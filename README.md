# Undangan Pernikahan Digital Premium (Ditya & Diva)

Struktur folder lengkap untuk diunggah ke GitHub atau di-hosting mandiri:

```text
wedding-invitation/
│
├── index.html            # Halaman utama undangan
├── css/
│   └── style.css         # Styling kustom tambahan
├── js/
│   └── script.js         # Logika interaktif (Countdown, RSVP, Buku Tamu, Music)
└── assets/
    ├── images/           # Masukkan file foto (hero-bg.jpg, groom.jpg, bride.jpg, gallery-1.jpg, dst)
    └── audio/            # Masukkan file musik latar belakang (backsound.mp3)
```

## Panduan Penggunaan & Personalisasi Tamu via URL:
Gunakan parameter `?to=` pada tautan untuk mengubah nama tamu secara otomatis:
`https://username.github.io/repository-name/?to=Bapak+Budi+Santoso`
